# Dashboard Interativo de Veículos

Este projeto faz parte da **Sprint 5: Ferramentas de Desenvolvimento de Software** da Tripleten. O objetivo é desenvolver e implantar um aplicativo web interativo em nuvem utilizando Python, Streamlit e Plotly.

## Tecnologias Utilizadas
- **Python**
- **Streamlit** (para construção da interface web)
- **Plotly Express** (para criação de gráficos interativos)
- **Pandas** (para manipulação e análise de dados)
- **Render** (plataforma de hospedagem em nuvem)

## Funcionalidades do Aplicativo
- **Cabeçalho Descritivo:** Apresenta o propósito do painel web.
- **Histograma Interativo:** Permite visualizar a distribuição da quilometragem (`km_driven`) dos veículos.
- **Gráfico de Dispersão:** Analisa a relação entre o preço de venda (`selling_price`) e a quilometragem (`km_driven`), categorizada por tipo de combustível (`fuel`).
